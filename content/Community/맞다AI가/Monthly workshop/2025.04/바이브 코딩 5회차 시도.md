리액트로 SNS 앱을 만들거야. 다음 피그마 링크의 디자인으로 로그인 화면을 만들어줘. 
https://www.figma.com/design/hmDJzp2LeXs7TD80U9mMVo/SNS?node-id=5-903&t=0wnDPTnzRXKCN5oY-4
그리고 로그인 API를 연결해줘. 
`127.0.0.1:8000/auth/login`으로 
{
  "username": "string",
  "password": "string"
}
형식의 post 요청을 보내면 돼. 
요청이 성공하면 아래와 같은 응답을 받을거야: 
{
  "access_token": "string",
  "refresh_token": "string",
  "token_type": "string"
}

이제 회원가입 페이지를 다음 피그마 디자인으로 만들어줘.  
[https://www.figma.com/design/hmDJzp2LeXs7TD80U9mMVo/SNS?node-id=5-916&t=0wnDPTnzRXKCN5oY-4](vscode-file://vscode-app/Applications/Visual%20Studio%20Code.app/Contents/Resources/app/out/vs/code/electron-sandbox/workbench/workbench.html)  
그리고 회원가입 API를 연결해줘.  
/auth/signup 으로  
{  
"username": "string",  
"password": "string"  
}  
형식의 post 요청을 보내면 돼.  
요청이 성공하면  
{  
"additionalProp1": {}  
}  
와 같은 응답을 받을거야.

CORS 오류가 생기지 않게 credentials 를 명시해줘.
