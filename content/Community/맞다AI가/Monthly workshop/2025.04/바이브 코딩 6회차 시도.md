1. [이 디자인](https://www.figma.com/design/hmDJzp2LeXs7TD80U9mMVo/SNS?node-id=5-903&t=4mBGCBPjd1m1nCxK-4)을 리액트로 구현해줘. `127.0.0.1:8000/auth/login` 으로 POST 요청을 보내면 돼. 
```json
{
  "username": "string",
  "password": "string"
}
```
의 형식으로 요청을 보내고 
```json
{
  "access_token": "string",
  "refresh_token": "string",
  "token_type": "string"
}
```
의 형식으로 응답을 받을거야. 

2. [회원가입 페이지](https://www.figma.com/design/hmDJzp2LeXs7TD80U9mMVo/SNS?node-id=5-916&t=kMbqMVUTrq1f2kfh-4)를 추가해줘. 
```json
{
  "username": "string",
  "password": "string"
}
```
`/auth/signup`으로 위 형식의 POST 요청을 보내. 
```json
{
  "additionalProp1": {}
}
```
성공하면 위와 같은 응답을 받을거야. 

3. [홈 화면](https://www.figma.com/design/hmDJzp2LeXs7TD80U9mMVo/SNS?node-id=6-2&t=8OW61jKqK8IjqlYA-4)을 추가해줘. 
   홈 화면을 보여줄 때는 먼저 게시글의 목록을 불러와야 해. 
   `/posts`로 GET 요청을 보내고, 게시글의 목록을 렌더링 해줘. 
![[Screenshot 2025-04-14 at 10.41.58.png]]
4. [게시글 작성 모달](https://www.figma.com/design/hmDJzp2LeXs7TD80U9mMVo/SNS?node-id=80-491&t=8OW61jKqK8IjqlYA-4)을 추가해줘. 
   게시글을 작성하면 `/posts`로 
   ```json
{
  "content": "string"
}
```
의 형태로 POST 요청을 보내야 해.
