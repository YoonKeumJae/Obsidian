## Docker

프로젝트 관리를 하면 버전과 관련된 문제가 상당히 많다. 
버전 뿐 아니라 추가적으로 설치해야하는 것들이 많다. 
버전들 사이 충돌 생기면 또 골치아파진다. 
내 컴퓨터에서는 안되는데요? 이런 상황이 생기는거다. 
Docker를 쓰면 이런 문제는 없어진다. 
모든 컴퓨터에서 똑같은 환경에서 앱을 실행할 수 있게 해준다. 
VM보다 훨씬 가볍다. 

## Docker Compose

우리 프로젝트의 경우 프론트, 백, 총 두개의 Dockerfile이 있다. 
지금은 두 개라서 괜찮을지 몰라도, 필요한 Dockerfile이 여러개(로깅 등)라면 일일이 치기 귀찮아진다. 
Docker compose를 쓴다면 여러 개의 Dockerfile을 한번에 정의하고 실행시킬 수 있다. 
솔직히 Dockerfile 두개밖에 없다고 docker run docker run 두번 하기엔 그거마저 귀찮지않냐.
