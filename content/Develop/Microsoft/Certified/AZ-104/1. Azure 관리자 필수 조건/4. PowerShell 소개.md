# PowerShell이란? 

명령줄 shell, 스크립트 언어로 구성됨.
윈도우의 관리작업 자동화 프레임워크로 시작됨. 

명령줄 shell은 GUI가 아닌 CLI를 사용. 
콘솔 사용의 장점은..

- GUI보다 빠름
- 명령의 일괄 처리 -> 자동화에 적합
- 클라우드 리소스, 기타 리소스와 상호작용
- 명령, 스크립트를 텍스트 파일에 저장, 소스 제어 시스템 사용 가능. 
	- 반복하고 감시할 수 있음.

## 기능

기존 shell과 일부 기능들을 공유함. 

- 기본 제공 도움말
- 파이프라인: 텍스트를 통해 개체에서 작동하므로 기존 shell과 다름. 
- 별칭: `cls`(clear the screen), `ls`(lsit the files) 등의 일반적인 별칭 사용. 

기존과 다른 점들: 

- 텍스트를 통해 개체에서 작동함. 
	- 입출력이 다를 수 있는 스크립트를 실행해야 함 -> 출력 서식 지정, 데이터 추출에 시간 소요됨. 
	- 하지만 PowerShell은 개체를 입출력으로 쓰기 때문에 시간 절약 가능. 
- cmdlet
	- PowerShell의 명령을 cmdlet이라 부름. 
	- 실행 파일이 아닌 런타임에 빌드됨 -> 구문 분석, 파이프라이닝에서 일관적 환경 제공
	- .NET Core로 빌드되는 오픈소스. 
- 다양한 명령
	- PowerShell 명령은 네이티브 실행 파일, cmdlet, 함수, 스크립트, 별칭일 수 있음. 
	- 모든 명령은 이 중 하나다. 
	- cmdlet은 명령의 유형을 지칭하므로 "명령"과 "cmdlet"이라는 단어를 교환하여 쓰는 경우가 많음.

# 명령 찾기

cmdlet은 컴파일 된 명령어임. 
동사 - 명사 형식으로 사용함. 
`Get-Verb` 명령어로 승인된 동사 목록을 볼 수 있음. 
아래는 출력의 일부임. 

```bash
Verb        AliasPrefix Group          Description
----        ----------- -----          -----------
Add         a           Common         Adds a resource to a container, or atta…
Clear       cl          Common         Removes all the resources from a contai…
```

동사와 설명이 출력되는걸 볼 수 있음. 
승인된 동사를 사용해야 하며, 동사에 대한 설명이 cmdlet의 함수에 적합한지 확인해야 함. 

- `Get-Command`: 사용 가능한 모든 cmdlet을 나열. 
- `Get-Help`: 기본 제공 도움말. 별칭인 `help`로도 가능하지만 `Get-Help`가 페이지로 출력해서 더 편함. 
- `Get-Member`: 명령에 대한 응답은 많은 속성을 갖고 있는 객체임. `Get-Member`로 속성을 볼 수 있음. 

## `Get-Command`로 명령 찾기

cmdlet인 `Get-Command`로 PowerShell의 모든 명령 목록을 볼 수 있음. 
근데 명령어가 한둘이 아닌 수천개니까 이걸 필터링 할 줄 알아야 함. 

위에서 언급한 동사-명사 구조를 기억해야함. 
`Get-Command`도 그렇고, `Get-Random`의 경우에도 동사-명사 구조임. 
플래그를 사용해서 원하는 명령의 동사/명사를 찾을 수 있음. 
찾을 때는 문자열 값이 필요한데.. 패턴을 통해 찾을 수 있다. 
패턴? [[3. Bash 소개]]에서 배웠던 그 패턴(와일드카드) 맞음.

예를 들어...

- `-Noun`: 명사인 검색어와 관련된 명령 찾기. 아래는 명사 부분이 `alias`로 시작하는 모든 cmdlet 검색함. 
	
```PowerShell
Get-Command -Noun alias*
```

- `-Verb`: 동사인 검색어와 관련된 명령 찾기. 아래는 동사 부분이 `Get`이고 명사 부분이 `alias`로 시작하는 검색.
```PowerShell
Get-Command -Verb Get -Noun alias*
```

# 연습 - 명령 찾기

파일과 관련된 명령어를 찾고싶음. 
그러면 "명사 부분이 File로 시작하는 명령어"를 검색하면 되지 않을까? 

```PowerShell
Get-Command -Noun File*
```

이렇게 하니까 요롷게 뜨네. 

```PowerShell
CommandType     Name                                               Version    Source
-----------     ----                                               -------    ------
Cmdlet          Get-FileHash                                       7.0.0.0    Microsoft.PowerShell.Utility
Cmdlet          Out-File                                           7.0.0.0    Microsoft.PowerShell.Utility
Cmdlet          Unblock-File                                       7.0.0.0    Microsoft.PowerShell.Utility
```

이제 동사 부분도 필터링해보자. 

```PowerShell
Get-Command -Verb Get -Noun File*
```

Get 으로 시작하는 명령어는 `Get-FileHash`가 있다고 뜸. 
요로코롬 하는거다.
