# Azure Cloud Shell 이란? 

리소스 관리를 위한 CLI (Azure CLI와 다름!).
설치 없이 브라우저로 접속 가능함. 
Azure CLI, PowerShell 모듈에 직접 접근 가능.
이중 암호화 준수됨. 
클라우드 스토리지(SSH키, 스크립트 등 저장) 제공: 다른 컴퓨터에서 중요 파일 접근 가능. 
Cloud Shell 편집기로, Cloud Shell 인터페이스에서, 이 파일들 변경 가능.

## 사용자 고유 스크립트, 파일에 접근

사용하는 동안, 스크립트 실행하거나 파일을 써야할 경우가 있겠지?
Azure Cloud Drive를 사용하면 Cloud Shell에 파일을 유지할 수 있음. 

![A screenshot of how to access CloudDrive in a Cloud Shell session.](https://learn.microsoft.com/ko-kr/training/modules/intro-to-azure-cloud-shell/media/use-azure-cloud-drive.png)

말 그대로 클라우드 드라이브임. 구글 드라이브 머 이런 것 처럼. 
그러면 다른 기기에서도 그 파일이 보이겠네? 맞음 ㅇㅇ
세션 닫고 다른 기기에서 접속해도 파일은 계속 유지됨. 

Cloud Shell은 'Azure Storage 파일 공유'를 매핑할 수도 있음. 
'Azure Storage 파일 공유' 는 서비스 이름임 ㅇㅇ.
Azure 파일 공유에 접근하면 Cloud Shell에서 공유된 내용 사용 가능함. 

Cloud Drive 또는 파일 공유에 있는 스크립트가 있음. 
이거 편집하려면 Cloud Shell 편집기로 하면 됨. 
- `{ }` 버튼을 누르고 파일을 열거나
- `code` 명령어 
를 사용해 파일 이름을 지정할 수 있음. 

![A screenshot of how to access the Cloud Shell editor mode.](https://learn.microsoft.com/ko-kr/training/modules/intro-to-azure-cloud-shell/media/cloud-shell-edit-scripts.png)

# Azure Cloud Shell을  사용해야 하는 경우

## 사용하는 경우

- 브라우저에서 보안 CLI 세션 열기
- Azure 리소스와 상호작용 (추가 기능 설치 X)
- 세션 간 파일 공유
- Bash, PowerShell 중 선호하는 것 사용
- 파일(스크립트 등) 편집
## 사용하면 *안되는* 경우

- 20분 이상 세션을 열 경우: 연결 끊어지고 (스크립트 실행 등의)상태 잃을 수 있음. 
- 관리자 권한(`sudo` 등) 필요한 경우
- VM, 컨테이너 등이 필요한 도구 설치해야 하는 경우
- 다른 지역 스토리지 필요한 경우 
	- 한 지역에서만 스토리지를 Azure Cloud Shell에 할당 가능. 
- 동시에 여러 세션 열어야 하는 경우
	- Azure Cloud Shell은 한번에 하나의 인스턴스만 허용함. 
	- 여러 구독, 테넌트 간의 동시 작업에는 적합하지 않음.
