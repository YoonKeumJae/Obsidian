본 과정에서는 IT 전문가들에게 Azure 구독 관리, ID 보안, 인프라 관리, 가상 네트워킹 구성, Azure 및 온-프레미스 사이트 연결, 네트워크 트래픽 관리, 저장소 솔루션 구현, 가상 머신 생성 및 확장, 웹 애플리케이션 및 컨테이너 구현, 데이터 백업 및 공유, 솔루션 모니터링 방법을 설명합니다.

#### 대상 그룹 프로필

본 과정은 Azure 관리자를 대상으로 합니다. Azure Administrator는 클라우드 환경에서 ID, 거버넌스, 스토리지, 컴퓨팅 및 가상 네트워크를 구현, 관리 및 모니터링합니다. Azure Administrator는 리소스를 프로비저닝, 크기 조정, 모니터링하여 적절히 조정합니다. 성공적인 Azure Administrator는 가상화, 네트워킹, ID 및 스토리지에 대한 경험으로 해당 역할을 시작합니다.

- VM, 가상 네트워킹, 가상 하드 디스크를 포함한 온-프레미스 가상화 기술에 대한 이해.
- TCP/IP, DNS(Domain Name System), VPN(가상 사설망), 방화벽 및 암호화 기술을 포함한 네트워크 구성 이해.
- 사용자, 그룹 및 역할 기반 액세스 제어 등 Active Directory 개념 이해.
- 백업 및 복원 작업을 포함한 회복력 및 재해 복구에 대한 이해.
